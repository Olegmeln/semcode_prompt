# Changelog

## 0.2.1-experimental — 2026-11-09

- Командный слой персонального языка: префикс `/`, команды `/F` (подтверждена) и `/A` (кандидат), операторы области `/--` (прямо или косвенно) и `/-` (только прямо).
- В схему записи токена добавлено необязательное поле `kind`: token / mode / command_prefix / command / scope_operator.
- Добавлен подтверждённый токен `LG` — «думай сам»: развить рамку самостоятельно.
- Спецификация Autocoder: раздел 3.1 с правилами разбора команд и операторов.
- Описание агента-редактора текстов для `/F`: `autocoder/agents/TEXT_EDITOR_AGENT.md`.
- `validate_repo.py` проверяет по схеме и рабочий словарь `personal-language.json`, а также дубли канонических форм.
- SemCode становится языковым слоем цифрового профиля в DigiTwin: `integrations/DIGITWIN.md`.
- Кандидат `F` — краткая форма `/F` отдельной строкой в конце сообщения.

## 0.2-experimental — 2026-07-31

- Система разделена на две самостоятельные ветки: `Autocoder` и `Codec`.
- Добавлен общий типизированный слой `Semantic IR`.
- Зафиксировано: вероятностное понимание выполняется в Autocoder, воспроизводимое сжатие — в Codec.
- Добавлена схема персонального языка пользователя.
- Добавлены правила обучения псевдонимов по подтверждённым интерпретациям.
- Добавлены версионированные словари Codec и контроль неизвестных токенов.
- Добавлены режимы `prompt`, `json`, `prompt+json`, `codec`, `api`.
- Добавлены профили целевых моделей и сред.
- Добавлен сквозной пример финансовой модели для Claude в Excel.
- Добавлен минимальный исполняемый прототип и автоматическая валидация JSON/YAML.

## 0.1-experimental — 2026-07-31

- Создано первоначальное ядро SemCode Prompt Autocoder.
- Определена нечёткая семантика команд.
- Добавлена модель уверенности H/M/L.
