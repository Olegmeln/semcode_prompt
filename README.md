# SemCode Prompt Autocoder v0.1

Экспериментальный человеко-ориентированный язык коротких команд для:

- автокодирования пользовательского намерения;
- автоматического составления качественных промптов;
- повторного использования контекста и памяти;
- адресного изменения ранее полученных результатов;
- передачи задач между ИИ, офисными приложениями и агентами.

## Основная идея

Пользователь пишет не полный промпт, а короткую семантическую запись. Язык намеренно не является полностью детерминированным: ИИ интерпретирует сокращения, опирается на контекст и память, оценивает уверенность и задаёт уточняющий вопрос только тогда, когда неоднозначность существенно влияет на результат.

Пример:

```text
FMtask→P? Cl@Excel new*FM in docs+ mem+
```

Интерпретация:

> Составь качественный промпт для Claude, встроенного в Excel, чтобы он создал новую финансовую модель на основе одного или нескольких приложенных документов, используя ранее сохранённый контекст.

## Быстрый запуск

1. Откройте `prompts/AUTOCODER_SYSTEM_PROMPT.md`.
2. Передайте системный промпт выбранной языковой модели.
3. Отправьте короткую команду SemCode.
4. Получите:
   - нормализованную кодированную команду;
   - расшифровку намерения;
   - готовый промпт;
   - список допущений;
   - уточнение только при критической неоднозначности.

## Структура репозитория

```text
spec/       спецификация языка и грамматика
schemas/    JSON-схемы команд и памяти
prompts/    системные промпты автокодировщика и компилятора
macros/     библиотека макрокоманд
examples/   практические примеры
 tests/     тестовые сценарии интерпретации
```
