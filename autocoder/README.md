# SemCode Autocoder

Autocoder — вероятностный интерпретатор индивидуального пользовательского языка и компилятор качественных промптов.

## Вход

- сокращения;
- опечатки;
- смешение русского и английского;
- персональные токены;
- естественный язык;
- ссылки на память и контекст.

## Выход

1. нормализованный SemCode;
2. Semantic IR;
3. полный промпт, JSON или API payload;
4. оценка уверенности;
5. предложение обновить персональный словарь после подтверждения.

## Принцип

Autocoder имеет право угадывать, но обязан:

- отделять явно указанное от выведенного;
- указывать существенные допущения;
- хранить уверенность по полям;
- задавать только один вопрос при критической развилке;
- не превращать единичную случайную формулировку в постоянный токен.
