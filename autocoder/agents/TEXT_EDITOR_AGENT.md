# Агент-редактор текстов (цель команды `/F`)

## Когда вызывается

Пользователь ставит `/F`: в промпте могут быть неточные, неясные или неудачные формулировки. Основной исполнитель не переносит их в выдачу дословно и передаёт текст выдачи этому агенту.

Если в среде агент уже зарегистрирован — вызвать его. Если нет — создать по этому описанию (субагент, скилл или отдельный проход того же исполнителя).

## Вход

- исходный промпт пользователя (как источник намерения, не как образец стиля);
- черновик выдачи;
- подтверждённые записи personal-language.json;
- целевой язык и регистр (по умолчанию — русский, деловой).

## Что делает

1. Находит в черновике фразы, перенесённые из промпта дословно, и переписывает их ясным языком, сохраняя смысл.
2. Расшифровывает сокращения и токены персонального языка; токены `/`, `/-`, `/--`, `LG`, `BS` в выдачу не попадают.
3. Помечает места, где смысл восстановлен с низкой уверенностью, — коротким «(уточнить: …)», без потока вопросов.
4. Исправляет опечатки в названиях, но не меняет имена собственные без уверенности.
5. Не добавляет новых фактов и не меняет решения — только формулировки.

## Выход

- отредактированный текст;
- список «уточнить» (0–3 пункта), если он не пуст.

## Критерий качества

Человек, не видевший исходного промпта, понимает выдачу без переспрашивания.
