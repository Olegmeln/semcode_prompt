# Autocoder Specification v0.2

## 1. Задача

Преобразовать пользовательский идиолект в Semantic IR и затем в качественный промпт или структурированный запрос.

## 2. Конвейер

```text
raw input
→ token candidates
→ personal-language lookup
→ contextual inference
→ normalized SemCode
→ Semantic IR
→ confidence gate
→ compiler/adapter
→ memory learning candidate
```

## 3. Персональный язык

Токен является персональным, если его значение подтверждено пользователем или устойчиво повторяется в одинаковом контексте.

Запись токена должна содержать:

- исходную форму;
- нормализованное значение;
- область действия;
- примеры;
- число подтверждений;
- уверенность;
- дату последнего использования;
- статус: candidate / confirmed / deprecated.

## 4. Обучение

### Автоматически разрешено

- повышать счётчик использования;
- сохранять временного кандидата в session memory;
- объединять очевидные варианты регистра и опечатки.

### Требует подтверждения

- новое глобальное значение сокращения;
- изменение ранее подтверждённого значения;
- сохранение чувствительного или потенциально конфликтного правила;
- распространение проектного токена на все проекты.

## 5. Уточнения

Autocoder не задаёт вопрос, если может:

- применить безопасное допущение;
- оставить placeholder;
- перечислить отсутствующие данные в итоговом промпте;
- вывести значение из подтверждённой памяти.

Вопрос обязателен, если без ответа возможны разные необратимые действия или несовместимые артефакты.

## 6. Компиляция качественного промпта

Промпт формируется не дословным расширением токенов, а по задаче. Он должен включать только релевантные секции:

- роль;
- цель;
- контекст;
- источники;
- действия;
- ограничения;
- формат результата;
- критерии проверки;
- работу с отсутствующими данными.

## 7. Адаптация под модель

Autocoder выбирает target adapter. Если модель не указана, используется `generic-llm`.

Адаптер может менять:

- формат tool calls;
- JSON-схему ответа;
- длину и структуру инструкций;
- способ передачи файлов;
- системный/пользовательский раздел;
- требования к XML/JSON/Markdown.
