# SemCode Codec

Codec — протокол воспроизводимого сжатия и передачи уже определённого намерения.

## Вход

- валидный Semantic IR;
- либо полный промпт, предварительно преобразованный в IR.

## Выход

- сжатая команда;
- идентификатор словаря и версия;
- при необходимости inline-словарь;
- checksum;
- ожидаемая схема декодированного IR.

## Запрет

Codec не должен угадывать неизвестные обязательные токены. Неизвестный токен вызывает ошибку или переход на полный промпт.
