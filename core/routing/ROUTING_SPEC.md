# Routing Specification v0.2

## Цель

Router определяет, какой контур использовать.

## Режимы

### `autocoder`

Используется, когда вход — сокращённый, персональный или неоднозначный пользовательский язык.

```text
user.lang → Autocoder → Semantic IR → Prompt/JSON
```

### `codec`

Используется, когда смысл уже формализован и требуется компактная передача.

```text
Semantic IR/full prompt → Codec → compressed payload
```

### `hybrid`

Используется по умолчанию для передачи пользовательской команды внешней модели:

```text
user.lang → Autocoder → Semantic IR → Codec → target model
```

### `direct`

Autocoder формирует полный промпт или API payload без сжатия.

## Сигналы маршрутизации

| Сигнал | Режим |
|---|---|
| `→prompt`, `→json`, `→api` | autocoder/direct |
| `→codec`, `compress`, `dict@...` | codec |
| `target:any`, `relay`, `send>` | hybrid |
| валидный Semantic IR на входе | codec или compiler |
| свободная персональная запись | autocoder |

## Правило безопасности

Нельзя отправлять сжатую команду внешней модели, если:

- словарь недоступен;
- версия словаря не совпадает;
- присутствуют неизвестные обязательные токены;
- декодированный IR не проходит валидацию.

В этих случаях Router должен переключиться на полный промпт или остановить передачу с диагностикой.
