# Примеры SemCode

## Создание промпта

```text
FMtask→P? Cl@Excel new*FM in docs+ q? →P
```

## Создание презентации

```text
PRES task→P? GPT@Chat new*deck in docs+ audience=investor mem+ →P
```

## Редактирование договора

```text
LAW edit~ @аванс.пополнение short- =law =nums !newfacts →clean
```

## Анализ таблицы

```text
DATA audit? GPT@Chat check! sheet:T1 focus=errors+logic →report
```

## Гибридная команда

```text
FM new** model in docs+ три сценария, срок 24 месяца, не выдумывать данные →artifact
```
