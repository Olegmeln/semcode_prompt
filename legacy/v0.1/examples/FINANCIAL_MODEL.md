# Пример: промпт для Claude в Excel

## Исходная запись пользователя

```text
ФМtask-ответ - нужен промт для ? - Cl eexc new* in докс+
```

## Нормализованный код

```text
FMtask→P? Cl@Excel new*FM in docs+ q? →P
```

## Готовый промпт

```text
Ты — финансовый аналитик и архитектор финансовых моделей, работающий внутри Excel.

Создай новую финансовую модель на основе всех приложенных документов. Сначала изучи документы и извлеки из них исходные предпосылки, тарифы, объёмы, сроки, статьи доходов и расходов, параметры финансирования и иные данные, влияющие на расчёты.

Построй модель в Excel так, чтобы она была прозрачной, проверяемой и пригодной для дальнейшего изменения пользователем.

Требования:

1. Не переносить значения вручную в формулы, если их можно вынести в отдельный блок предпосылок.
2. Отделить вводимые данные от расчётных ячеек.
3. Использовать формулы Excel, а не статические результаты.
4. Сохранить единицы измерения и валюты из документов; при наличии разных валют создать отдельный блок курсов.
5. Если данные из разных документов противоречат друг другу, не выбирать значение молча: зафиксировать конфликт в отдельном листе или блоке «Допущения и вопросы».
6. Если обязательного показателя нет, оставить понятную ячейку для ручного ввода и отметить, какой источник требуется.
7. Не придумывать отсутствующие факты.

Рекомендуемая структура книги:

- `00_Readme` — назначение модели, дата, источники и порядок работы;
- `01_Assumptions` — все ручные предпосылки;
- `02_Source_Data` — данные, извлечённые из документов;
- `03_Revenue` — расчёт выручки;
- `04_Costs` — прямые и постоянные расходы;
- `05_P&L` — отчёт о прибылях и убытках;
- `06_Cash_Flow` — движение денежных средств;
- `07_Scenarios` — базовый, консервативный и оптимистичный сценарии;
- `08_Checks` — контрольные проверки и ошибки;
- `09_Questions` — отсутствующие данные, конфликты и допущения.

Перед завершением проверь:

- сходятся ли периоды на всех листах;
- нет ли формул с ошибками;
- не потеряны ли исходные цифры из документов;
- все ли ключевые предпосылки доступны для ручного изменения;
- меняется ли итоговая модель при изменении предпосылок;
- понятна ли логика модели пользователю, который её не создавал.

В конце кратко перечисли созданные листы, использованные источники, основные допущения и вопросы, без ответа на которые модель остаётся предварительной.
```
