# Prompt Compiler Template

Используй этот шаблон после интерпретации SemCode-команды.

```text
РОЛЬ
Ты — [роль, подходящая задаче и среде].

ЦЕЛЬ
[конкретный ожидаемый результат].

КОНТЕКСТ
[релевантный контекст из команды, документов и памяти].

ВХОДНЫЕ МАТЕРИАЛЫ
[перечень источников и порядок их приоритета].

ЗАДАЧА
1. [основное действие]
2. [структурирование]
3. [расчёт/анализ/редактирование]
4. [проверка]

ТРЕБОВАНИЯ
- [структура результата]
- [ограничения]
- [формулы, ссылки, формат]
- [правила обработки отсутствующих данных]

САМОПРОВЕРКА
Перед выдачей проверь:
- полноту;
- внутреннюю согласованность;
- отсутствие вымышленных данных;
- соответствие источникам;
- соответствие формату.

ФОРМАТ ВЫВОДА
[точный формат результата].
```
